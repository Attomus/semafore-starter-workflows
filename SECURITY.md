# Security Policy

## Reporting Security Issues

Report suspected vulnerabilities privately to `security@attomus.com`. You can
also use a private vulnerability report from this repository's **Security** tab.

Do not open a public issue or include real service tokens, device keys,
credentials, or customer data. Include the affected workflow, reproduction
steps, and expected impact where possible.

## Scope

This policy covers unsafe secret handling, permissions, expression use, and
other security defects in the workflow examples in this repository.

For vulnerabilities in the Action itself, use the
[Action security policy](https://github.com/Attomus/semafore-github-action/security/policy).
Report general SemaFore product or infrastructure issues through the
[Attomus vulnerability disclosure policy](https://attomus.com/security/).
Third-party platform or dependency vulnerabilities should be reported to their
maintainers unless the problem is caused by how these workflows use them.

## Supported Version

The latest revision on `main` is supported. Copy updated workflow examples when
a security correction is published.

## Response Commitment

Attomus aims to acknowledge reports within 48 hours and provide an initial
assessment, including severity and an expected remediation timeline, within
7 days. We will coordinate a fix and disclosure date with the reporter before
details are made public.
